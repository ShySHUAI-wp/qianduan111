## 附录：关键技术点

### A. 进程管理
使用 Python `subprocess` 模块执行命令：
```python
process = subprocess.Popen(
    command,
    stdout=subprocess.PIPE,
    stderr=subprocess.STDOUT,
    text=True,
    bufsize=1,
    cwd="/home/shuo/cola/lerobot"
)
```

### B. 实时输出捕获
使用线程读取进程输出，通过队列传递：
```python
def read_output(process, queue):
    for line in iter(process.stdout.readline, ''):
        queue.put(line)
```

### C. WebSocket 通信
前端：
```typescript
socket.on('command_output', (data) => {
  appendLog(data.line);
});
```

后端：
```python
await sio.emit('command_output', {
    'commandId': cmd_id,
    'line': line
})
```

### D. 相机预览（MJPEG）
后端返回 MJPEG 流：
```python
def generate_frames(camera_id):
    cap = cv2.VideoCapture(camera_id)
    while True:
        ret, frame = cap.read()
        if not ret:
            break
        _, buffer = cv2.imencode('.jpg', frame)
        yield (b'--frame\r\n'
               b'Content-Type: image/jpeg\r\n\r\n' +
               buffer.tobytes() + b'\r\n')
```

前端显示：
```tsx
<img src="/api/cameras/preview?id=0" />
```
