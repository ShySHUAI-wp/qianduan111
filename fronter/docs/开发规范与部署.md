# 开发规范与部署文档

## 1. 开发环境搭建

### 1.1 前置要求

- **Node.js**: v18.0.0 或更高版本
- **Python**: 3.10 或更高版本
- **pnpm**: 8.0.0 或更高版本（推荐）
- **Git**: 2.0 或更高版本
- **操作系统**: Linux (Ubuntu 20.04+ 推荐)

### 1.2 前端环境搭建

```bash
# 进入前端项目目录
cd /home/shuo/cola/lerobot_cobot/fronter

# 创建前端项目（如果还未创建）
pnpm create vite fronter-web --template react-ts
cd fronter-web

# 安装依赖
pnpm install

# 安装项目依赖
pnpm add antd @ant-design/icons react-router-dom zustand axios socket.io-client
pnpm add react-markdown remark-gfm react-syntax-highlighter
pnpm add -D @types/react-syntax-highlighter

# 安装开发工具
pnpm add -D eslint prettier eslint-config-prettier eslint-plugin-react
pnpm add -D @typescript-eslint/parser @typescript-eslint/eslint-plugin

# 启动开发服务器
pnpm dev
```

### 1.3 后端环境搭建


## 2. 代码规范

### 2.1 前端代码规范

#### 2.1.1 命名规范

- **组件文件名**: 大驼峰 `ComponentName.tsx`
- **工具文件名**: 小驼峰 `utilityName.ts`
- **常量**: 全大写下划线 `CONSTANT_NAME`
- **变量/函数**: 小驼峰 `variableName`, `functionName`
- **类型/接口**: 大驼峰 `InterfaceName`, `TypeName`
- **私有变量**: 下划线前缀 `_privateName`（不推荐，优先使用 TypeScript private）

#### 2.1.2 目录规范

```
src/
├── components/      # 可复用组件（大驼峰命名）
│   └── Button/
│       ├── index.tsx
│       ├── Button.tsx
│       └── Button.module.css
├── pages/          # 页面组件（大驼峰命名）
├── stores/         # 状态管理（use 前缀 + 大驼峰）
├── services/       # API 服务（小驼峰）
├── hooks/          # 自定义 Hooks（use 前缀 + 大驼峰）
├── utils/          # 工具函数（小驼峰）
└── types/          # 类型定义（大驼峰）
```

### 2.2 后端代码规范

#### 2.2.1 命名规范

- **文件名**: 小写下划线 `file_name.py`
- **类名**: 大驼峰 `ClassName`
- **函数/方法**: 小写下划线 `function_name`
- **变量**: 小写下划线 `variable_name`
- **常量**: 全大写下划线 `CONSTANT_NAME`
- **私有方法**: 下划线前缀 `_private_method`

#### 2.2.2 代码风格 (PEP 8)

```python
# 导入顺序：标准库 → 第三方库 → 本地模块
import os
import sys
from typing import List, Optional

from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

from app.services import port_service
from app.utils import validators

# 类定义
class PortInfo(BaseModel):
    path: str
    description: str
    hwid: str

# 函数定义（类型注解）
async def find_ports() -> List[PortInfo]:
    """
    查找所有可用串口

    Returns:
        List[PortInfo]: 串口列表

    Raises:
        RuntimeError: 当无法访问串口时
    """
    ports = await port_service.find_all_ports()
    return ports

# 常量定义
LEROBOT_PATH = "/home/shuo/cola/lerobot"
MAX_CONCURRENT_COMMANDS = 5
```

#### 2.2.3 类型注解

```python
from typing import Optional, List, Dict, Any

# 函数参数和返回值类型
def process_data(
    data: Dict[str, Any],
```

#### 2.2.4 异常处理

```python
from fastapi import HTTPException

# 自定义异常
class DeviceNotFoundError(Exception):
    pass

# 在路由中处理异常
@app.post("/api/ports/find")
async def find_port():
    try:
        port = await port_service.find_port_interactive()
        return {"code": 0, "data": {"port": port}}
    except DeviceNotFoundError as e:
        raise HTTPException(status_code=404, detail=str(e))
    except Exception as e:
        logger.error(f"Unexpected error: {e}")
        raise HTTPException(status_code=500, detail="Internal server error")
```

## 3. Git 工作流

### 3.1 分支管理

```
main          # 主分支（生产环境）
├── develop   # 开发分支
│   ├── feature/tutorial-page       # 功能分支
│   ├── feature/port-finder         # 功能分支
│   └── feature/camera-finder       # 功能分支
└── hotfix/fix-port-permission      # 紧急修复分支
```

### 3.2 提交规范

使用 [Conventional Commits](https://www.conventionalcommits.org/) 规范：

```
<type>(<scope>): <subject>

<body>

<footer>
```

**类型（type）：**
- `feat`: 新功能
- `fix`: 修复 bug
- `docs`: 文档更新
- `style`: 代码格式调整（不影响功能）
- `refactor`: 重构（既不是新功能也不是 bug 修复）
- `perf`: 性能优化
- `test`: 测试相关
- `chore`: 构建过程或辅助工具的变动

**示例：**
```bash
git commit -m "feat(port-finder): add interactive port finding feature"
git commit -m "fix(camera): resolve preview stream memory leak"
git commit -m "docs(api): update API documentation for commands"
```

### 3.3 工作流程

```bash
# 1. 从 develop 创建功能分支
git checkout develop
git pull origin develop
git checkout -b feature/my-feature

# 2. 开发并提交
git add .
git commit -m "feat(scope): description"

# 3. 推送到远程
git push origin feature/my-feature

# 4. 创建 Pull Request 到 develop

# 5. Code Review 通过后合并

# 6. 删除功能分支
git branch -d feature/my-feature
git push origin --delete feature/my-feature
```

#### 5.1.2 Nginx 配置

```nginx
# /etc/nginx/sites-available/fronter
server {
    listen 80;
    server_name your-domain.com;  # 或服务器 IP

    # 前端静态文件
    location / {
        root /home/shuo/cola/lerobot_cobot/fronter/fronter-web/dist;
        try_files $uri $uri/ /index.html;
    }

    # API 代理
    location /api {
        proxy_pass http://localhost:8000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # WebSocket 代理
    location /ws {
        proxy_pass http://localhost:8000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 86400;  # 24小时
    }
}
```

#### 5.4.2 Python 日志配置

```python
# app/config.py
import logging
from logging.handlers import RotatingFileHandler

def setup_logging():
    logger = logging.getLogger("fronter")
    logger.setLevel(logging.INFO)

    # 控制台输出
    console_handler = logging.StreamHandler()
    console_handler.setLevel(logging.INFO)

    # 文件输出（日志轮转）
    file_handler = RotatingFileHandler(
        "/var/log/fronter/app.log",
        maxBytes=10 * 1024 * 1024,  # 10MB
        backupCount=5
    )
    file_handler.setLevel(logging.INFO)

    # 格式化
    formatter = logging.Formatter(
        '%(asctime)s - %(name)s - %(levelname)s - %(message)s'
    )
    console_handler.setFormatter(formatter)
    file_handler.setFormatter(formatter)

    logger.addHandler(console_handler)
    logger.addHandler(file_handler)

    return logger
```

## 7. 常见问题排查

### 7.1 前端无法访问后端

**检查：**
1. 后端服务是否运行：`sudo systemctl status fronter-backend`
2. 端口是否开放：`sudo netstat -tulpn | grep 8000`
3. Nginx 配置是否正确：`sudo nginx -t`
4. 查看 Nginx 错误日志：`sudo tail -f /var/log/nginx/error.log`

### 7.2 WebSocket 连接失败

**检查：**
1. Nginx WebSocket 代理配置是否正确
2. 查看浏览器控制台的 WebSocket 错误
3. 检查后端 WebSocket 实现

### 7.3 命令执行失败

**检查：**
1. lerobot 环境是否正确：`which lerobot-find-port`
2. 设备权限：`ls -l /dev/ttyACM0`
3. 查看后端日志：`sudo journalctl -u fronter-backend -f`

### 7.4 串口权限不足

```bash
# 添加用户到 dialout 组
sudo usermod -aG dialout $USER

# 重新登录使权限生效
```

## 9. 性能优化建议

### 9.1 前端优化

- 使用 React.lazy() 进行路由懒加载
- 使用 useMemo 和 useCallback 避免不必要的重渲染
- 虚拟滚动优化长列表
- 图片懒加载
- 生产构建启用代码分割

### 9.2 后端优化

- 使用异步 I/O（asyncio）
- 限制并发进程数量
- 使用缓存（如 Redis，可选）
- 优化数据库查询（如果使用数据库）
