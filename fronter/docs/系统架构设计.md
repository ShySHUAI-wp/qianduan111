### 3.2 核心服务设计

#### ProcessManager - 进程管理器

```python
class ProcessManager:
    """管理 lerobot 命令的执行"""

    def __init__(self):
        self.processes: Dict[str, subprocess.Popen] = {}
        self.output_queues: Dict[str, Queue] = {}

    async def execute_command(
        self,
        command_id: str,
        command: str,
        cwd: str = "/home/shuo/cola/lerobot"
    ) -> None:
        """执行命令并捕获输出"""

    async def stop_command(self, command_id: str) -> None:
        """停止正在执行的命令"""

    def get_output(self, command_id: str) -> List[str]:
        """获取命令输出"""
```

## 4. 通信协议设计

### 4.1 REST API

所有 API 返回统一格式：

```typescript
interface ApiResponse<T> {
  code: number;        // 状态码：0 成功，非 0 失败
  message: string;     // 消息
  data?: T;            // 数据
}
```

### 4.2 WebSocket 协议

#### 客户端 → 服务端

```typescript
// 执行命令
{
  type: 'execute_command',
  payload: {
    command: 'lerobot-calibrate',
    params: { ... }
  }
}

// 停止命令
{
  type: 'stop_command',
  payload: {
    commandId: 'xxx'
  }
}

// 订阅日志
{
  type: 'subscribe_logs',
  payload: {
    commandId: 'xxx'
  }
}
```

#### 服务端 → 客户端

```typescript
// 命令输出
{
  type: 'command_output',
  payload: {
    commandId: 'xxx',
    line: '...',
    timestamp: '2025-02-01T10:00:00Z'
  }
}

// 命令状态更新
{
  type: 'command_status',
  payload: {
    commandId: 'xxx',
    status: 'running' | 'completed' | 'error',
    exitCode?: number
  }
}

// 需要用户输入（如 lerobot-find-port 的确认）
{
  type: 'input_required',
  payload: {
    commandId: 'xxx',
    prompt: 'Remove the USB cable and press Enter',
    options: ['confirm', 'cancel']
  }
}
```

## 5. 数据流设计

### 5.1 端口查找流程

```
用户点击"查找端口"
  ↓
前端调用 API: POST /api/ports/find
  ↓
后端执行 lerobot-find-port
  ↓
WebSocket 推送消息："请拔掉对应串口"
  ↓
前端显示确认弹窗
  ↓
用户点击"确定"或"取消"
  ↓
前端通过 WebSocket 发送确认
  ↓
后端继续执行命令
  ↓
WebSocket 推送结果："端口为 /dev/ttyACM0"
  ↓
前端将端口添加到选项列表
```

### 5.2 命令执行流程

```
用户配置参数并点击"执行"
  ↓
前端验证参数
  ↓
前端调用 API: POST /api/commands/execute
  ↓
后端生成命令 ID，创建子进程
  ↓
后端通过 WebSocket 实时推送命令输出
  ↓
前端在日志查看器中显示输出
  ↓
命令执行完成
  ↓
后端推送完成状态
  ↓
前端更新 UI 状态
```

## 6. 安全设计

### 6.1 命令白名单

只允许执行以下 lerobot 命令：
- `lerobot-find-port`
- `lerobot-find-cameras`
- `lerobot-calibrate`
- `lerobot-teleoperate`
- `lerobot-record`

### 6.2 参数验证

- 端口路径必须匹配 `/dev/tty*` 格式
- 相机索引必须为非负整数
- 所有路径参数禁止包含 `..` 或其他危险字符

### 6.3 权限管理

- 对 `/dev/ttyACM*` 设备的权限检查和提示
- 需要 sudo 权限时，提供清晰的提示信息

## 7. 性能优化

### 7.1 前端优化

- 路由懒加载：使用 React.lazy() 分割代码
- Markdown 缓存：已加载的教程文档缓存到内存
- 虚拟滚动：日志查看器使用虚拟滚动处理大量日志

### 7.2 后端优化

- 异步处理：所有 I/O 操作使用异步
- 进程池：限制同时运行的子进程数量
- 输出缓冲：使用队列缓冲命令输出，批量发送

## 8. 错误处理

### 8.1 前端错误处理

- 网络错误：自动重试机制（最多 3 次）
- WebSocket 断连：自动重连
- 命令执行失败：显示详细错误信息和建议

### 8.2 后端错误处理

- 子进程崩溃：捕获异常，清理资源
- 设备不可用：返回友好的错误提示
- 超时处理：命令执行超时自动终止
