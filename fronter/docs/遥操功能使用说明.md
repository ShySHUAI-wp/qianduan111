# 遥操功能使用说明

## 功能概述

遥操功能允许你通过 Leader 机械臂控制 Follower 机械臂，实现实时的机械臂遥操控制。

## 核心组件

### 1. 机器人端口配置（Robot/Follower）

**单臂机器人**（如 so100_follower, so101_follower）：
- 需要配置 **1个** USB端口
- 点击"配置机器人端口"按钮
- 按照提示插拔USB设备进行端口识别
- 在列表中勾选找到的端口

**双臂机器人**（如 bi_so100_follower）：
- 需要配置 **2个** USB端口（左臂和右臂）
- 第一个端口为左臂，第二个端口为右臂
- 最多只能选择2个端口

### 2. 遥操端口配置（Teleop/Leader）

**单臂遥操**（如 so100_leader, so101_leader）：
- 需要配置 **1个** USB端口

**双臂遥操**（如 bi_so100_leader）：
- 需要配置 **2个** USB端口（左臂和右臂）

### 3. 相机配置（可选）

- 可以选择 **多个** 相机进行图像采集
- 点击"配置相机"按钮
- 点击"查找相机"自动检测所有可用相机
- 在列表中勾选要使用的相机
- 可以点击"预览"按钮查看相机画面

### 4. 显示选项

**显示数据界面**：
- **不显示**：只进行遥操，不启动可视化界面
- **显示（Rerun可视化）**：启动 Rerun 可视化服务，在网页中实时查看遥操数据

**FPS**：
- 设置遥操控制的帧率（1-120）
- 默认为 60 FPS

## 使用流程

### 步骤1：配置机器人端口

1. 选择机器人类型（单臂或双臂）
2. 点击"配置机器人端口"按钮
3. 在弹出的对话框中点击"查找端口"
4. 按照提示操作：
   - 步骤1：插入USB设备，点击确定
   - 步骤2：拔掉USB设备，点击确定
   - 步骤3：重新插入USB设备，点击确定
5. 在列表中勾选识别出的端口
6. 关闭对话框

### 步骤2：配置遥操端口

与步骤1相同，配置遥操设备的端口。

### 步骤3：配置相机（可选）

1. 点击"配置相机"按钮
2. 点击"查找相机"按钮
3. 在列表中勾选要使用的相机
4. 可以点击"预览"查看相机画面
5. 关闭对话框

### 步骤4：启动遥操

1. 确认所有必要的端口已配置
2. 选择是否启用"显示数据界面"
3. 点击"开始遥操"按钮
4. 如果启用了数据显示：
   - 系统会自动启动 Rerun 可视化服务
   - 等待几秒后，下方会显示 Rerun 可视化窗口
   - 可以在可视化窗口中查看机械臂状态、相机画面等数据

### 步骤5：停止遥操

1. 点击"停止遥操"按钮
2. 系统会自动停止遥操进程
3. 如果启用了数据显示，也会自动停止 Rerun 可视化服务

## Rerun 可视化说明

### 什么是 Rerun？

Rerun 是一个专业的机器人数据可视化工具，可以实时显示：
- 机械臂关节位置
- 相机画面
- 传感器数据
- 3D 场景可视化

### 工作原理

1. **自动启动**：
   - 当你启用"显示数据界面"并点击"开始遥操"时
   - 系统会自动在后台启动 Rerun viewer（可视化服务器）
   - 服务器监听在 `http://127.0.0.1:9876`

2. **数据推送**：
   - lerobot-teleoperate 进程会将实时数据推送到 Rerun viewer
   - 包括机械臂状态、相机画面等

3. **网页显示**：
   - 通过 iframe 在网页中嵌入 Rerun 可视化界面
   - 通过后端代理 `/api/rerun/proxy` 访问 Rerun 服务
   - 解决了浏览器 CORS 跨域问题

4. **自动停止**：
   - 当你点击"停止遥操"时
   - 系统会自动停止 Rerun viewer 进程

### 常见问题

**Q: Rerun 可视化界面显示空白？**

A: 可能原因：
1. Rerun viewer 还没有完全启动，等待几秒
2. 检查日志输出，查看是否有错误信息
3. 手动检查 Rerun 服务状态：访问 `/api/rerun/status`

**Q: 数据显示延迟？**

A: 可以尝试：
1. 降低 FPS 设置
2. 减少相机数量
3. 关闭不必要的可视化层

**Q: 相机画面不显示？**

A: 检查：
1. 相机是否正确配置和选中
2. 相机权限是否授予
3. 检查日志中是否有相机相关的错误

## 技术架构

### 后端 API

1. **遥操控制**：
   - `POST /api/commands/teleoperate` - 启动遥操
   - `POST /api/commands/stop` - 停止遥操
   - `GET /api/commands/status` - 查询状态
   - `GET /api/commands/output` - 获取输出

2. **Rerun 可视化**：
   - `POST /api/rerun/start` - 启动 Rerun viewer
   - `POST /api/rerun/stop` - 停止 Rerun viewer
   - `GET /api/rerun/status` - 查询 Rerun 状态
   - `ALL /api/rerun/proxy/*` - 代理 Rerun HTTP 请求

3. **端口管理**：
   - `GET /api/ports/list` - 列出所有端口
   - `POST /api/ports/permission/check` - 检查端口权限
   - `POST /api/ports/permission/grant` - 授予端口权限

4. **相机管理**：
   - `GET /api/cameras/list` - 列出所有相机
   - `GET /api/cameras/stream/{camera_id}` - 相机预览流

### 前端组件

1. **Teleoperate** - 遥操主界面
2. **PortFinder** - 端口查找和选择
3. **CameraFinder** - 相机查找和选择
4. **CameraPreview** - 相机预览
5. **LogViewer** - 日志查看器

### 进程管理

使用 `CommandManager` 管理后台进程：
- 异步进程启动
- 实时输出捕获
- 优雅停止（SIGTERM → SIGKILL）
- 进程组管理（防止子进程泄漏）

## 开发说明

### 添加新的机器人类型

1. 在前端的 Select 选项中添加新类型
2. 更新 `isBimanualRobot` 函数判断逻辑
3. 确保后端能正确处理新类型的参数

### 调试技巧

1. **查看日志**：所有操作都会输出到日志区域
2. **查看进程列表**：访问 `/api/commands/list`
3. **查看进程输出**：访问 `/api/commands/output?commandId=xxx`
4. **检查 Rerun 状态**：访问 `/api/rerun/status`

### 已知限制

1. **相机配置**：当前只传递相机ID，后续需要转换为完整的相机配置对象
2. **Rerun 可视化**：需要确保系统已安装 `rerun-cli`
3. **端口权限**：Linux 系统可能需要手动添加用户到 `dialout` 组
