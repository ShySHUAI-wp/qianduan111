# 技术栈选型方案

## 1. 前端框架

### 推荐方案：React + TypeScript
**理由：**
- **React**：组件化开发，生态成熟，社区活跃
- **TypeScript**：类型安全，提高代码可维护性，减少运行时错误
- **适配性强**：支持复杂的交互逻辑和状态管理

### 备选方案：Vue 3 + TypeScript
**理由：**
- 上手更简单，模板语法更直观
- 性能优秀，响应式系统成熟
- 适合中小型项目快速开发

## 2. UI 组件库

### 推荐：Ant Design (antd)
**理由：**
- 企业级 UI 设计，组件丰富
- 中文文档完善
- 提供完整的表单、按钮、弹窗、树形控件等本项目所需组件
- 支持主题定制

### 备选：Material-UI (MUI)
**理由：**
- Google Material Design 风格
- 组件现代化，动画效果好
- 国际化支持好

## 3. 状态管理

### 推荐：Zustand
**理由：**
- 轻量级（约 1KB）
- API 简洁，学习成本低
- 支持 TypeScript
- 适合本项目中等复杂度的状态管理需求

### 备选：Redux Toolkit
**理由：**
- Redux 官方推荐方案
- 适合大型应用
- 开发者工具强大
- 社区支持好

## 4. 路由管理

### 推荐：React Router v6
**理由：**
- React 官方推荐的路由方案
- 支持嵌套路由，适合侧边栏多页面结构
- API 简洁，性能优秀

## 5. Markdown 渲染

### 推荐：react-markdown + remark-gfm
**理由：**
- 支持 GitHub Flavored Markdown
- 可自定义组件渲染
- 支持代码高亮（配合 react-syntax-highlighter）
- 安全（默认过滤 HTML）

### 配置示例：
```typescript
import ReactMarkdown from 'react-markdown';
import remarkGfm from 'remark-gfm';
import { Prism as SyntaxHighlighter } from 'react-syntax-highlighter';

<ReactMarkdown
  remarkPlugins={[remarkGfm]}
  components={{
    code({ node, inline, className, children, ...props }) {
      // 代码高亮配置
    }
  }}
>
  {markdownContent}
</ReactMarkdown>
```

## 6. HTTP 请求

### 推荐：Axios
**理由：**
- 功能完善，支持请求/响应拦截器
- 支持取消请求
- 自动转换 JSON 数据
- 支持浏览器和 Node.js

## 7. 后端服务

### 推荐：FastAPI (Python)
**理由：**
- 与 lerobot Python 项目无缝集成
- 高性能异步框架
- 自动生成 OpenAPI 文档
- 支持 WebSocket（用于实时数据传输）
- 原生支持类型注解

### 技术要点：
- **进程管理**：使用 `subprocess` 模块调用 lerobot 命令
- **实时输出**：使用 WebSocket 推送命令执行进度
- **端口管理**：提供端口查找、权限检查接口
- **嵌入式页面代理**：反向代理 lerobot 的数据可视化页面

## 8. 实时通信

### 推荐：Socket.IO (前端) + python-socketio (后端)
**理由：**
- 支持实时双向通信
- 自动重连机制
- 支持房间（room）概念，方便分组管理
- 适合命令执行进度实时推送

### 备选：WebSocket API（原生）
**理由：**
- 浏览器原生支持
- 轻量级，无需额外库
- 但需要自己实现重连等机制

## 9. 构建工具

### 推荐：Vite
**理由：**
- 开发服务器启动极快
- 热模块替换（HMR）性能优秀
- 生产构建基于 Rollup
- 原生支持 TypeScript
- 配置简单

### 配置建议：
```typescript
// vite.config.ts
export default {
  server: {
    proxy: {
      '/api': 'http://localhost:8000',  // 后端 API 代理
      '/ws': {
        target: 'ws://localhost:8000',
        ws: true
      }
    }
  }
}
```

## 10. 代码规范

### ESLint + Prettier
**理由：**
- ESLint：代码质量检查
- Prettier：代码格式化
- 配合 Git hooks（husky + lint-staged）自动格式化

## 11. 视频流处理

### 推荐：iframe 嵌入
**理由：**
- lerobot 的数据可视化页面可直接通过 iframe 嵌入
- 简单可靠，无需重复开发

### 相机预览：
- 使用 HTML5 `<video>` 元素
- 通过 WebRTC 或后端流式传输（MJPEG/WebSocket）

## 12. 开发环境

### 推荐配置：
- **Node.js**: v18+ LTS
- **Python**: 3.10+
- **包管理器**: pnpm（更快，更节省磁盘空间）
- **IDE**: VSCode + ESLint + Prettier + Volar/TypeScript 插件

## 技术栈总结

| 技术领域 | 推荐方案 | 版本要求 |
|---------|---------|---------|
| 前端框架 | React + TypeScript | React 18+ |
| UI 组件库 | Ant Design | 5.x |
| 状态管理 | Zustand | 4.x |
| 路由管理 | React Router | 6.x |
| Markdown 渲染 | react-markdown | 9.x |
| HTTP 请求 | Axios | 1.x |
| 后端框架 | FastAPI | 0.100+ |
| 实时通信 | Socket.IO | 4.x |
| 构建工具 | Vite | 5.x |
| 包管理器 | pnpm | 8.x |

## 项目初始化命令

```bash
# 创建 React + TypeScript 项目
pnpm create vite fronter-web --template react-ts

# 安装依赖
cd fronter-web
pnpm install

# 安装 UI 库和工具
pnpm add antd @ant-design/icons
pnpm add react-router-dom
pnpm add zustand
pnpm add axios
pnpm add socket.io-client
pnpm add react-markdown remark-gfm react-syntax-highlighter
pnpm add -D @types/react-syntax-highlighter

# 安装开发工具
pnpm add -D eslint prettier eslint-config-prettier
```

```bash
# 后端项目初始化
cd ../fronter-backend
python -m venv venv
source venv/bin/activate  # Linux/Mac
pip install fastapi uvicorn python-socketio python-multipart
```
