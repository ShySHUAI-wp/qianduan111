- 教程
- 底盘控制(是实现ros2的导航)
- 机械臂控制(是使用本项目的lerobot)

## 机械臂控制
暂时使用lerobot，其中要实现

能够调用终端的命令，这个只能在`/home/shuo/cola/lerobot`,其本质是在调用项目中一些配置文件，能进行以下命令：

-  查找端口
```bash
lerobot-find-port
```
这里应当有一个按钮，按动后来一个弹窗，弹窗提示请拔掉对应串口，能选择取消和确定，取消会直接取消操作，确定的话相当于命令行按enter，之后会显示哪个串口被拔掉了，显示串口要变成一个选项，能提供给之后的`校准机械臂`、`遥操机械臂`用

- 查找video接口
```bash
lerobot-find-cameras opencv
```
这里应当有一个按钮，按动会显示可以用的相机，显示可用的相机要变成一个选项，能提供给之后的`遥操机械臂`用，并且双击这个选项就能调用相机预览

- 接口查找权限和授权
```bash
ls -alh /dev/ttyACM0
sudo chmod 666 /dev/ttyACM0
```
之前`查找端口`和`查找video接口`要显示其 读 写 权限，并且可以被勾选

- 校准机械臂
设置leader
```bash
lerobot-calibrate \
    --teleop.type=so101_leader \
    --teleop.port=/dev/ttyACM1 \
    --teleop.id=my_awesome_leader_arm
```
通过`查找端口`的选项选择`teleop.port`，并且可以自定义`teleop.id`,默认`teleop.id`为my_awesome_leader_arm

设置follower
```bash
lerobot-calibrate \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyACM0 \
    --robot.id=my_awesome_follower_arm
```
通过`查找端口`的选项选择`robot.port`，并且可以自定义`robot.id`,默认`robot.id`为my_awesome_follower_arm

- 遥操机械臂
不带相机
```bash
lerobot-teleoperate \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyACM0 \
    --robot.id=my_awesome_follower_arm \
    --teleop.type=so101_leader \
    --teleop.port=/dev/ttyACM1 \
    --teleop.id=my_awesome_leader_arm \
    --display_data=true
```
通过`查找端口`的选项选择`teleop.port`和`robot.port`，并且可以自定义`teleop.id`,默认`teleop.id`为为my_awesome_leader_arm，可以自定义`teleop.id`,默认`teleop.id`为my_awesome_leader_arm
`是否查看数据界面`的选项能选择勾选或不勾选，其中其结果也是一个ip+端口的网页，这个网页也嵌套进去

带相机
```bash
lerobot-teleoperate \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyACM0 \
    --robot.id=my_awesome_follower_arm \
    --robot.cameras="{ front: {type: opencv, index_or_path: 2, width: 640, height: 480, fps: 30, fourcc: "MJPG", rotation: "ROTATE_180"}, side: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30, fourcc: "MJPG"}}" \
    --teleop.type=so101_leader \
    --teleop.port=/dev/ttyACM1 \
    --teleop.id=my_awesome_leader_arm \
    --display_data=true \
    --fps=30
```
通过`查找端口`的选项选择`teleop.port`和`robot.port`，并且可以自定义`teleop.id`,默认`teleop.id`为为my_awesome_leader_arm，可以自定义`teleop.id`,默认`teleop.id`为my_awesome_leader_arm
通过`查找video接口`来选择`robot.cameras`的内容，并且可以自定义宽度，高度和fps，以及选择角度，默认分别为640 480 30 180度
`是否查看数据界面`的选项能选择勾选或不勾选，其中其结果也是一个ip+端口的网页，这个网页也嵌套进去

数据采集
```bash
lerobot-record \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyACM0 \
    --robot.id=my_awesome_follower_arm \
    --robot.cameras="{ front: {type: opencv, index_or_path: 2, width: 640, height: 480, fps: 30, fourcc: "MJPG", rotation: "ROTATE_180"}, side: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30, fourcc: "MJPG"}}" \
    --teleop.type=so101_leader \
    --teleop.port=/dev/ttyACM1\
    --teleop.id=my_awesome_leader_arm \
    --display_data=true  \
    --dataset.repo_id=dj/test005 \
    --dataset.num_episodes=5 \
    --dataset.single_task="Grab the pink cube" \
    --dataset.push_to_hub=false \
    --dataset.episode_time_s=30 \
    --dataset.reset_time_s=20 \
    --dataset.fps=30
```

通过`查找端口`的选项选择`teleop.port`和`robot.port`，并且可以自定义`teleop.id`,默认`teleop.id`为为my_awesome_leader_arm，可以自定义`teleop.id`,默认`teleop.id`为my_awesome_leader_arm
通过`查找video接口`来选择`robot.cameras`的内容，并且可以自定义宽度，高度和fps，以及选择角度，默认分别为640 480 30 180度
`是否查看数据界面`的选项能选择勾选或不勾选，其中其结果也是一个ip+端口的网页，这个网页也嵌套进去
可以设置`dataset.num_episodes=5` `dataset.single_task` `dataset.episode_time_s` `dataset.reset_time_s` `dataset.fps` 以及 `dataset.repo_id`

其中`dataset.num_episodes=5` `dataset.single_task` `dataset.episode_time_s` `dataset.reset_time_s` `dataset.fps`按照默认值设计
