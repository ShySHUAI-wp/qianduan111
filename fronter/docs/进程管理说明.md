# 进程管理功能说明

## 功能概述

后端现在完整实现了命令进程的后台管理，包括：
- ✅ 启动进程
- ✅ 停止进程
- ✅ 查询状态
- ✅ 实时输出捕获
- ✅ 进程列表

## 核心实现

### 命令管理器 (`command_manager.py`)

**文件**: `fronter/fronter-backend/app/services/command_manager.py`

#### CommandProcess 类

跟踪单个命令进程的信息：
- `command_id`: 命令ID
- `command`: 执行的命令
- `process`: asyncio 子进程对象
- `status`: 状态（running, completed, failed, stopped, error）
- `output_lines`: 输出行列表（带时间戳）
- `start_time`: 启动时间
- `end_time`: 结束时间
- `exit_code`: 退出码

#### CommandManager 类

管理所有命令进程：

**主要方法**:

1. `start_command(command_id, command)` - 启动命令
   - 创建异步子进程
   - 启动输出捕获任务
   - 返回 CommandProcess 对象

2. `stop_command(command_id)` - 停止命令
   - 优雅终止（SIGTERM）
   - 等待5秒
   - 强制终止（SIGKILL）

3. `get_command_status(command_id)` - 获取状态
   - 返回命令的详细状态信息

4. `get_command_output(command_id, offset, limit)` - 获取输出
   - 支持分页获取输出行

5. `list_commands()` - 列出所有命令

6. `cleanup_finished_commands(keep_last_n)` - 清理已完成的命令

## 重要特性

### 1. 遥操模式不限制时长

**代码位置**: `commands.py:72-74`

```python
# 遥操时长 - 遥操模式不限制时长，注释掉
# if request.teleop_time_s:
#     cmd_parts.append(f"--teleop_time_s={request.teleop_time_s}")
```

遥操模式下，进程会一直运行直到：
- 用户手动停止
- 发生错误
- 按Ctrl+C中断

### 2. 实时输出捕获

**实现**: `command_manager.py:_capture_output()`

- 异步读取 stdout
- 合并 stderr 到 stdout
- 每行添加时间戳
- 自动处理进程退出

### 3. 优雅停止

**实现**: `command_manager.py:stop_command()`

```python
# 1. 发送 SIGTERM（优雅终止）
process.terminate()

# 2. 等待5秒
await asyncio.wait_for(process.wait(), timeout=5.0)

# 3. 超时则强制 SIGKILL
process.kill()
```

### 4. 自动状态更新

进程结束时自动更新状态：
- 退出码 0 → `completed`
- 退出码 非0 → `failed`
- 手动停止 → `stopped`

## 使用示例

### Python 客户端

```python
import httpx
import asyncio

async def test_teleoperate():
    async with httpx.AsyncClient() as client:
        # 1. 启动遥操
        response = await client.post(
            "http://localhost:8000/api/commands/teleoperate",
            json={
                "robot_type": "so101_follower",
                "robot_port": "/dev/ttyACM0",
                "robot_id": "my_follower",
                "teleop_type": "so101_leader",
                "teleop_port": "/dev/ttyACM1",
                "teleop_id": "my_leader",
                "fps": 60,
                "display_data": True,
            },
        )
        result = response.json()
        command_id = result["data"]["commandId"]
        print(f"Started: {command_id}")

        # 2. 定期查询状态和输出
        for _ in range(10):
            await asyncio.sleep(2)

            # 查询状态
            status_resp = await client.get(
                f"http://localhost:8000/api/commands/status?commandId={command_id}"
            )
            status = status_resp.json()["data"]
            print(f"Status: {status['status']}, Output lines: {status['outputLines']}")

            # 获取最新输出
            output_resp = await client.get(
                f"http://localhost:8000/api/commands/output?commandId={command_id}&offset=0&limit=5"
            )
            output = output_resp.json()["data"]
            for line in output["lines"]:
                print(f"  {line}")

        # 3. 停止命令
        stop_resp = await client.post(
            "http://localhost:8000/api/commands/stop",
            json={"commandId": command_id},
        )
        print("Stopped:", stop_resp.json())

asyncio.run(test_teleoperate())
```

## 错误处理

### 1. 进程启动失败

```json
{
  "detail": "启动遥操失败: [Errno 2] No such file or directory: 'lerobot-teleoperate'"
}
```

### 2. 命令不存在

```json
{
  "detail": "命令不存在: teleop-invalid"
}
```

### 3. 命令无法停止

```json
{
  "code": 1,
  "message": "命令无法停止，当前状态: completed",
  "data": {...}
}
```
