# Fronter 项目开发文档

## 项目简介

Fronter 是一个基于 Web 的机械臂控制平台，旨在提供无代码化的机械臂操作界面。通过该平台，用户可以：
- 查找和配置串口设备
- 查找和配置相机设备
- 校准机械臂（Leader 和 Follower）
- 进行机械臂遥操
- 采集训练数据
- 查看教程文档

本项目基于 LeRobot 机械臂控制框架，通过 Web 界面封装了 LeRobot 的命令行工具。

## 技术栈概览

### 前端
- **框架**: React 18 + TypeScript
- **UI 库**: Ant Design 5.x
- **状态管理**: Zustand
- **路由**: React Router 6
- **HTTP 客户端**: Axios
- **实时通信**: Socket.IO Client
- **Markdown 渲染**: react-markdown
- **构建工具**: Vite

### 后端
- **框架**: FastAPI
- **实时通信**: python-socketio
- **异步**: asyncio
- **进程管理**: subprocess
- **串口通信**: pyserial
- **相机**: OpenCV

## 关键技术要点

### 1. 进程管理
后端使用 Python `subprocess` 模块执行 LeRobot 命令，并通过 WebSocket 实时推送输出。

### 2. 交互式命令处理
通过 WebSocket 双向通信实现交互式命令（如 `lerobot-find-port` 需要用户确认）。

### 3. 相机预览
使用 MJPEG 流式传输实现相机实时预览。

### 4. 数据可视化嵌入
使用 iframe 嵌入 LeRobot 的数据可视化页面。

## 重要提示

### 关于 dataset.repo_id
原需求中的 `dataset.repo_id` 用于指定 HuggingFace Hub 仓库。根据需求修改，改为**本地存储路径**。

需要确认 `lerobot-record` 是否支持本地路径。如果不支持，需要：
1. 修改后端逻辑，将数据保存到指定路径
2. 或修改 LeRobot 源码以支持本地路径

### 关于权限
- 串口设备（`/dev/ttyACM*`）需要读写权限
- 相机设备（`/dev/video*`）需要读权限
- 建议将用户添加到 `dialout` 组：`sudo usermod -aG dialout $USER`

### 关于安全性
- 后端需要验证命令白名单，只允许执行 LeRobot 相关命令
- 参数需要格式验证，防止注入攻击
- 文件路径需要防止路径遍历攻击
