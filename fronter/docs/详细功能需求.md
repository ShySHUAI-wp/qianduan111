# 详细功能需求文档

## 1. 侧边栏导航

### 1.1 功能描述
左侧固定侧边栏，提供多页面导航功能。

### 1.2 UI 设计
- 宽度：200px - 250px
- 可折叠/展开
- 高亮显示当前选中页面
- 支持图标 + 文字

### 1.3 菜单项
```
┌─────────────────┐
│  📚 教程         │  → /tutorial
│  🚗 底盘控制    │  → /chassis-control (预留)
│  🤖 机械臂控制  │  → /robot-control
└─────────────────┘
```

### 1.4 交互逻辑
- 点击菜单项切换页面
- 教程菜单项支持二级展开（显示教程目录）
- URL 变化时自动更新高亮状态

## 2. 教程页面

### 2.1 功能描述
解析并显示 `fronter/turtorial` 目录下的 Markdown 教程文档。

### 2.2 目录结构要求
```
fronter/turtorial/
├── 教程分支1/         # 一级目录（文件夹）
│   ├── 1.md          # 二级文档（Markdown 文件）
│   └── 2.md
├── 教程分支2/
│   └── 3.md
└── 其他文件（忽略）
```

**严格要求：** 只解析 `文件夹/md文档` 结构，其他结构忽略。

### 2.3 UI 布局

```
┌──────────────────────────────────────────┐
│  教程                                     │
├────────────┬─────────────────────────────┤
│            │                             │
│ 目录树     │     Markdown 渲染区          │
│            │                             │
│ - 教程分支1 │   # 标题                     │
│   - 1      │   内容...                    │
│   - 2      │                             │
│ - 教程分支2 │   ```python                 │
│   - 3      │   代码块                     │
│            │   ```                       │
│            │                             │
└────────────┴─────────────────────────────┘
```

### 2.4 详细需求

#### 2.4.1 目录树组件
- 左侧显示树形目录结构
- 一级节点：文件夹名称（可折叠/展开）
- 二级节点：Markdown 文件名（不含 .md 后缀）
- 默认展开第一个文件夹
- 高亮显示当前选中的文档

#### 2.4.2 Markdown 渲染器
- 支持 GitHub Flavored Markdown (GFM)
- 代码高亮（支持常见语言：Python, Bash, JavaScript, TypeScript 等）
- 支持图片（相对路径基于教程目录）
- 支持表格、任务列表、删除线等
- 支持数学公式（可选，使用 KaTeX）

#### 2.4.3 文件读取逻辑
**前端实现方式（推荐）：**
1. 后端提供 API 扫描目录结构：`GET /api/tutorials/tree`
2. 后端提供 API 读取文档内容：`GET /api/tutorials/content?path=教程分支1/1.md`
3. 前端缓存已读取的文档

**响应示例：**
```json
// GET /api/tutorials/tree
{
  "code": 0,
  "data": {
    "教程分支1": ["1.md", "2.md"],
    "教程分支2": ["3.md"]
  }
}

// GET /api/tutorials/content?path=教程分支1/1.md
{
  "code": 0,
  "data": {
    "path": "教程分支1/1.md",
    "content": "# 测试\n测试内容..."
  }
}
```

### 2.5 交互流程
1. 页面加载时，调用 `/api/tutorials/tree` 获取目录结构
2. 渲染目录树，默认选中第一个文档
3. 加载第一个文档的内容并渲染
4. 用户点击其他文档时，加载对应内容
5. 使用 URL 参数记录当前文档：`/tutorial?path=教程分支1/1.md`

## 3.2 查找端口功能

### 3.2.1 功能描述
调用 `lerobot-find-port` 查找串口设备。

### 3.2.2 UI 组件
- 按钮：【查找端口】
- 弹窗：确认拔掉串口的对话框
- 下拉选择框：显示已找到的端口（供后续功能使用）

### 3.2.3 交互流程

```
用户点击【查找端口】
  ↓
显示弹窗："请拔掉对应串口"
  ┌─────────────────────────┐
  │  请拔掉对应的 USB 串口   │
  │                         │
  │  [取消]      [确定]      │
  └─────────────────────────┘
  ↓
用户点击【取消】 → 取消操作，关闭弹窗
用户点击【确定】 → 执行 lerobot-find-port
  ↓
后端执行命令，实时输出日志
  ↓
命令执行完成，解析输出
  ↓
显示找到的端口：/dev/ttyACM0
  ↓
将端口添加到端口选择器的选项列表
```

### 3.2.4 端口显示要求
- 显示端口路径（如 `/dev/ttyACM0`）
- 显示读写权限状态（✅ 可读写 / ❌ 无权限）
- 提供权限授予按钮（调用 `sudo chmod 666 /dev/ttyACM0`）

### 3.2.5 API 接口

**查找端口：**
```
POST /api/ports/find
Response:
{
  "code": 0,
  "data": {
    "commandId": "cmd-1234",
    "port": "/dev/ttyACM0"
  }
}
```

**检查权限：**
```
GET /api/ports/permission?port=/dev/ttyACM0
Response:
{
  "code": 0,
  "data": {
    "port": "/dev/ttyACM0",
    "readable": true,
    "writable": true,
    "mode": "0666"
  }
}
```

**授予权限：**
```
POST /api/ports/grant-permission
Body: { "port": "/dev/ttyACM0" }
Response: { "code": 0, "message": "权限已授予" }
```

### 3.3.2 UI 组件

```
┌───────┬──────────────┬─────────┬────────┬──────┬──────┐
│ 选择  │ 相机 ID      │ 分辨率  │ FPS    │ 权限 │ 操作 │

### 3.3.4 相机预览
- 双击相机条目或点击【预览】按钮
- 弹出模态框显示相机实时画面
- 提供关闭按钮

### 3.3.5 相机配置
用户可以为每个相机配置：
- **名称**：front / side（用于 `robot.cameras` 参数）

- **高度**：默认 480
- **FPS**：默认 30

      ...
    ]
  }
}
```

```

## 3.4 校准机械臂功能

### 3.4.1 功能描述
调用 `lerobot-calibrate` 校准 Leader 或 Follower 机械臂。

### 3.4.2 UI 布局

```
┌────────────────────────────────────────────────┐
│  校准机械臂                                     │
├────────────────────────────────────────────────┤
│                                                 │
│  Leader 校准                Follower 校准       │
│  ┌──────────────────┐      ┌──────────────────┐│
│  │ 端口: [选择...▼] │      │ 端口: [选择...▼] ││
│  │ ID: [________]   │      │ ID: [________]   ││
│  │ 默认:            │      │ 默认:            ││
│  │ my_awesome_      │      │ my_awesome_      ││
│  │ leader_arm       │      │ follower_arm     ││
│  │                  │      │                  ││
│  │ [开始校准]       │      │ [开始校准]       ││
│  └──────────────────┘      └──────────────────┘│
└────────────────────────────────────────────────┘
```

### 3.4.3 参数配置

**Leader 校准：**
- `teleop.type`: `so101_leader`（固定）
- `teleop.port`: 从端口选择器中选择
- `teleop.id`: 默认 `my_awesome_leader_arm`，用户可自定义

**Follower 校准：**
- `robot.type`: `so101_follower`（固定）
- `robot.port`: 从端口选择器中选择
- `robot.id`: 默认 `my_awesome_follower_arm`，用户可自定义

### 3.4.4 执行命令

**Leader 校准：**
```bash
lerobot-calibrate \
    --teleop.type=so101_leader \
    --teleop.port=/dev/ttyACM1 \
    --teleop.id=my_awesome_leader_arm
```

**Follower 校准：**
```bash
lerobot-calibrate \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyACM0 \
    --robot.id=my_awesome_follower_arm
```

### 3.4.5 交互流程
1. 用户从端口下拉框中选择端口
2. 用户输入自定义 ID（可选）
3. 用户点击【开始校准】
4. 前端调用 API 执行校准命令
5. 实时显示命令输出到日志区
6. 命令执行完成后显示成功/失败提示

### 3.6.3 参数配置

**基础参数：**
- `robot.type`: `so101_follower`
- `robot.port`: 端口选择
- `robot.id`: 自定义 ID
- `teleop.type`: `so101_leader`
- `teleop.port`: 端口选择
- `teleop.id`: 自定义 ID
- `display_data`: 布尔值

**相机参数（必需）：**
- `robot.cameras`: JSON 字符串（同遥操功能）
- `fps`: 整体 FPS

**数据集参数：**
- `dataset.repo_id`: **改为本地存储路径**（如 `/home/shuo/datasets/my_data`）
- `dataset.num_episodes`: 采集轮数（默认 5）
- `dataset.single_task`: 任务描述（如 "Grab the pink cube"）
- `dataset.episode_time_s`: 单轮时长（默认 30 秒）
- `dataset.reset_time_s`: 重置时长（默认 20 秒）
- `dataset.fps`: FPS（默认 30）
- `dataset.push_to_hub`: `false`（固定，不上传到 HuggingFace Hub）

### 3.6.4 存储路径说明

原需求中的 `dataset.repo_id=dj/test005` 改为本地存储路径。

**修改方案：**
- 用户指定一个存储目录（如 `/home/shuo/datasets/my_data`）
- 后端将该路径传递给 `lerobot-record` 的 `--dataset.repo_id` 参数
- 文件会自动存储在该目录下，文件名从 `0000000` 开始编号

**注意：** 需要确认 lerobot-record 是否支持本地路径作为 `repo_id`。如果不支持，需要修改后端逻辑或 lerobot 源码。

### 3.6.5 采集进度显示

数据采集过程中，需要实时显示：
- 当前进度：第 X/Y 轮
- 进度条
- 当前轮的状态（采集中/重置中）
- 剩余时间
